# Personal Portfolio Website - Dhanishkanth S B

A modern, minimal, performance-focused personal portfolio website built with semantic HTML5, modern CSS3 variables, and vanilla JavaScript.

## Features
- **Zero Build Step:** Fully self-contained single-file architecture (`index.html`) — opens instantly in any browser.
- **Theme Support:** Automatic dark/light mode following system preferences (`prefers-color-scheme`), plus manual persistent toggle switch (`localStorage`).
- **Typography:** Fused pairing with *Syne* (distinctive, confident headings) and *Plus Jakarta Sans* (clean, legible body font).
- **Responsive Layout:** Mobile-first architecture tested across 375px (mobile), 768px (tablet), and 1280px+ (desktop).
- **SEO & Social Previews:** Pre-configured Open Graph, Twitter Cards, and structured meta tags.
- **Accessibility:** Skip-to-content link, semantic HTML elements, keyboard navigation with visible focus rings, and WCAG AA contrast compliance.

## Quick Start
1. Double click `index.html` to open directly in Google Chrome, Microsoft Edge, Firefox, or Safari.
2. Drop your resume PDF into this directory and name it `resume.pdf` to enable one-click resume downloads.
3. Deploy for free via GitHub Pages, Vercel, or Netlify by simply pushing this repository.
